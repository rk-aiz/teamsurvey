提供されたSQLスキーマに基づき、テーブル定義書を以下にまとめます。

-----

## 1\. surveys (アンケート本体テーブル)

| 物理名                 | 論理名       | データ型                          | NULL許容 | 主キー  | 外部キー              | 既定値            | 説明                               |
| :------------------ | :-------- | :---------------------------- | :----- | :--- | :---------------- | :------------- | :------------------------------- |
| `id`                | 内部管理用ID   | `serial`                      | 否      | TRUE |                   |                | 内部管理用ID (主キー)                    |
| `title`             | アンケートタイトル | `VARCHAR(255)`                | 否      |      |                   |                | アンケートタイトル                        |
| `status`            | ステータス     | `survey_status`               | 否      |      |                   | `'DRAFT'`      | アンケートステータス (`survey_status`型)    |
| `result_visibility` | 集計結果の公開範囲 | `result_visibility`           | 否      |      |                   | `'ADMIN_ONLY'` | 集計結果の公開範囲 (`result_visibility`型) |
| `target_group_id`   | 対象グループID  | `INTEGER`                     | 可      |      | `user_groups(id)` |                | 対象グループ (ON DELETE SET NULL)      |
| `deadline`          | 回答締め切り日時  | `timestamp without time zone` | 可      |      |                   |                | 回答締め切り日時 (NULLの場合は無期限)           |
| `created_at`        | 作成日       | `timestamp without time zone` | 可      |      |                   |                | 作成日                              |
| `updated_at`        | 更新日       | `timestamp without time zone` | 可      |      |                   |                | 更新日                              |

-----

## 2\. answer\_patterns (回答パターン（親）テーブル)

| 物理名            | 論理名     | データ型           | NULL許容 | 主キー  | 外部キー | 既定値     | 制約       | 説明                    |
| :------------- | :------ | :------------- | :----- | :--- | :--- | :------ | :------- | :-------------------- |
| `id`           | 内部管理用ID | `serial`       | 否      | TRUE |      |         |          | 内部管理用ID (主キー)         |
| `pattern_name` | 管理用名称   | `VARCHAR(100)` | 否      |      |      |         | `UNIQUE` | 管理用名称（例：5段階評価、Yes/No） |
| `is_deleted`   | 論理削除フラグ | `BOOLEAN`      | 否      |      |      | `FALSE` |          | 論理削除フラグ               |

-----

## 3\. answer\_pattern\_items (回答パターンの選択肢（子）テーブル)

| 物理名                 | 論理名      | データ型           | NULL許容 | 主キー  | 外部キー                  | 既定値 | 説明                       |
| :------------------ | :------- | :------------- | :----- | :--- | :-------------------- | :-- | :----------------------- |
| `id`                | 内部管理用ID  | `serial`       | 否      | TRUE |                       |     | 内部管理用ID (主キー)            |
| `answer_pattern_id` | 回答パターンID | `INTEGER`      | 否      |      | `answer_patterns(id)` |     | 外部キー (ON DELETE CASCADE) |
| `item_text`         | 選択肢テキスト  | `VARCHAR(255)` | 否      |      |                       |     | 選択肢の内容                   |
| `item_order`        | 表示順序     | `INTEGER`      | 否      |      |                       |     | 表示順序                     |

-----

## 4\. questions (設問テーブル)

| 物理名                 | 論理名      | データ型            | NULL許容 | 主キー  | 外部キー                  | 既定値     | 説明                                                 |
| :------------------ | :------- | :-------------- | :----- | :--- | :-------------------- | :------ | :------------------------------------------------- |
| `id`                | 内部管理用ID  | `serial`        | 否      | TRUE |                       |         | 内部管理用ID (主キー)                                      |
| `survey_id`         | アンケートID  | `INTEGER`       | 否      |      | `surveys(id)`         |         | アンケートID (外部キー, ON DELETE CASCADE)                  |
| `answer_pattern_id` | 回答パターンID | `INTEGER`       | 可      |      | `answer_patterns(id)` |         | 回答パターンID (外部キー) ※自由記述の場合はNULL (ON DELETE SET NULL) |
| `question_text`     | 質問文      | `text`          | 可      |      |                       |         | 質問文                                                |
| `question_type`     | 回答形式     | `question_type` | 否      |      |                       |         | 回答形式 (`question_type`型)                            |
| `is_required`       | 必須回答フラグ  | `BOOLEAN`       | 否      |      |                       | `FALSE` | 必須回答かどうか                                           |
| `display_order`     | 表示順      | `INTEGER`       | 否      |      |                       | `0`     | 表示順                                                |
| `is_deleted`        | 論理削除フラグ  | `BOOLEAN`       | 否      |      |                       | `FALSE` | 論理削除フラグ                                            |

-----

## 5\. authentications (認証情報テーブル)

| 物理名            | 論理名     | データ型                          | NULL許容 | 主キー  | 外部キー | 既定値    | 制約       | 説明                                    |
| :------------- | :------ | :---------------------------- | :----- | :--- | :--- | :----- | :------- | :------------------------------------ |
| `username`     | ユーザー名   | `VARCHAR(50)`                 | 否      | TRUE |      |        |          | ユーザー名 (主キー)                           |
| `password`     | パスワード   | `VARCHAR(255)`                | 否      |      |      |        |          | パスワード                                 |
| `email`        | メールアドレス | `VARCHAR(255)`                | 否      |      |      |        | `UNIQUE` | メールアドレス                               |
| `display_name` | 表示名     | `VARCHAR(50)`                 | 否      |      |      |        |          | 表示名                                   |
| `created_at`   | 作成日     | `timestamp without time zone` | 可      |      |      |        |          | 作成日                                   |
| `updated_at`   | 更新日     | `timestamp without time zone` | 可      |      |      |        |          | 更新日                                   |
| `enabled`      | 有効フラグ   | `BOOLEAN`                     | 否      |      |      | `TRUE` |          | 有効フラグ (論理削除用: TRUE=有効, FALSE=無効/削除済み) |

-----

## 6\. responses (回答ヘッダーテーブル)

| 物理名          | 論理名     | データ型                          | NULL許容 | 主キー  | 外部キー                        | 既定値            | 説明                               |
| :----------- | :------ | :---------------------------- | :----- | :--- | :-------------------------- | :------------- | :------------------------------- |
| `id`         | 内部管理用ID | `serial`                      | 否      | TRUE |                             |                | 内部管理用ID (主キー)                    |
| `survey_id`  | アンケートID | `INTEGER`                     | 否      |      | `surveys(id)`               |                | 外部キー (ON DELETE CASCADE)         |
| `user_id`    | ユーザーID  | `VARCHAR(50)`                 | 否      |      | `authentications(username)` |                | ログインユーザー (必須, ON DELETE CASCADE) |
| `status`     | 回答の状態   | `response_status`             | 否      |      |                             | `'UNVERIFIED'` | 回答の状態 (有効、無効、テストなど)              |
| `created_at` | 作成日     | `timestamp without time zone` | 可      |      |                             |                | 作成日                              |
| `updated_at` | 更新日     | `timestamp without time zone` | 可      |      |                             |                | 更新日 (再回答された日時)                   |

-----

## 7\. response\_details (回答明細テーブル)

| 物理名                      | 論理名     | データ型      | NULL許容 | 主キー  | 外部キー                       | 既定値 | 説明                             |
| :----------------------- | :------ | :-------- | :----- | :--- | :------------------------- | :-- | :----------------------------- |
