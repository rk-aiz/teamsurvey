## アプリケーション概要

Java + Spring Boot で構築されたオンラインアンケートシステム。
管理者がアンケートを作成・配布し、ユーザーが回答することができる。
社内や、小～中規模のグループでアンケートを取る際に、インターネット経由でアンケートを行い、データ入力の手間を減らす。

## 用語の定義

<dl>
    <dt>ユーザー</dt>
    <dd>アンケートの回答をおこなう人</dd>
    <dt>管理者</dt>
    <dd>アンケート作成・発行、ユーザーの管理を行う人。</dd>
    <dt>アンケート</dt>
    <dd>複数の設問をまとめたもの</dd>
    <dt>設問(Question)</dt>
    <dd>単一の質問文と、その質問タイプのセット。</dd>
    <dt>設問タイプ(Question Type)</dt>
    <dd>単一選択肢の設問か複数選択肢の設問か、記述式回答の設問かを表す。</dd>
    <dt>回答(Response)</dt>
    <dd>ユーザーがアンケートに対して入力したもの</dd>
    <dt>トークン(Token)</dt>
    <dd>ユーザーが個別のアンケートにアクセスするための識別子</dd>
</dl>

## 機能

**管理者機能**

    アンケート作成・編集: 質問の追加、並べ替え、必須設定など。

        設問タイプ: 単一選択(Radio)、複数選択(Checkbox)、自由記述(Text)

        締め切り設定: 無期限、日時による締め切り。

        ステータス管理: 下書き / 公開中 / 終了。

        アクセス制限: ユーザーグループ指定。

        集計の公開設定: 集計結果の公開範囲設定
            管理者のみ / 対象のユーザーグループ / 全ユーザー。

    アカウント管理:

        ユーザー・管理者アカウントの作成・編集・削除。

**ユーザー機能**

    初期画面:

        ログインフォーム

    ユーザーホーム:

        ユーザーが回答可能なアンケート一覧

        閲覧権限を持つアンケート結果の一覧

        自身のアカウント情報設定画面への遷移

    回答画面:

        各設問に対する回答の入力

        バリデーション: 必須チェック、回答期限チェック、重複回答防止（ユニークトークン時）。

    アカウント情報設定画面

        ログインパスワード変更

        メールアドレス変更

## システム化の範囲

社内や、グループ内用アンケートを想定しているため、ユーザーによる新規アカウント作成機能は実装しない。

運用規模は ～500人程度を想定する。
