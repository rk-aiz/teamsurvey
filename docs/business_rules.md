# ビジネスルール (Business Rules)

## アンケート (Survey)

### ステータス遷移 (Status Transition)

アンケートのステータス (`SurveyStatus`) は以下のルールに従って遷移します。

| 現在のステータス       | 遷移可能なステータス | 条件・備考                                   |
| :--------------------- | :------------------- | :------------------------------------------- |
| **DRAFT** (下書き)     | **PUBLISHED**        | アンケートを公開する際。                     |
|                        | **DELETED**          | 下書きを削除する際。                         |
| **PUBLISHED** (公開中) | **CLOSED**           | 回答受付を終了する際。                       |
| **CLOSED** (終了)      | **DELETED**          | 終了したアンケートを削除する際。             |
| **DELETED** (削除済)   | -                    | 論理削除、または物理削除されるため遷移なし。 |

**制約事項:**

- **PUBLISHED** から直接 **DELETED** に遷移することはできません。誤って公開中のアンケートを削除しないよう、一度 **CLOSED** にする必要があります。
